# WSS / WSS2 Scroll-Scrub Technical Lab

Isolated prototype for evaluating scroll-driven media before integrating anything into the WSS portfolio page.

The lab intentionally does **not** modify the current WSS content page, editorial sections, or WSS2 iframe.

## Local layout

```text
wss/scrub-lab/
  index.html
  scrub-lab.css
  scrub-lab.js
  encode-media.sh
  TECHNICAL-REPORT.md
  media/                  # experimental/local assets; do not overwrite originals
```

The repository does not contain the publication/source media. Populate `media/` locally with:

```text
wss-source.mov            # original WSS intro, for A/source comparison
wss-baseline.mp4          # existing 8.6s web WSS derivative, for A2
wss2-source.mp4           # original WSS2 preview, for A/A2 comparison
wss-scrub.mp4             # generated by encode-media.sh
wss2-scrub.mp4            # generated by encode-media.sh
wss-opening.jpg
wss2-opening.jpg
wss-theme.png             # WSS Stage setting artwork
wss2-theme.png            # WSS2 Main Theme Poster
```

Run the derivative encoder with:

```bash
./encode-media.sh '/path/WSS intro.mov' '/path/WSS2 Preview.MP4' ./media
```

Then serve the lab over HTTP, for example from this directory:

```bash
python3 -m http.server 8765
```

Open `http://127.0.0.1:8765/`.

## Media modes

- `A / SOURCE`: original source media.
- `A2 / WEB BASELINE`: existing 8.6s WSS web derivative plus original WSS2 preview.
- `B / SHORT-GOP`: experimental 720p/30fps H.264 derivatives, 0.30s GOP, no audio.

## Contracts under test

- X = edition reveal; Y = normalized show time; neither modifies the other.
- Scroll is authoritative and reversible.
- Only the latest useful media target is allowed to survive a busy seek.
- Film → hold → theme is derived from progress and therefore reversible.
- Ordinary mobile touch stays native vertical scroll; the divider handle alone owns horizontal drag.
- Reduced motion does not continuously seek video.
- Static fallbacks prevent a black screen before media is seekable.

See `TECHNICAL-REPORT.md` for measured results and the production recommendation.
